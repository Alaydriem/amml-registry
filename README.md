# AMML registry

The official registry of AMML (Alaydriem's Modded Minecraft Loader) releases and mods. The AMML launcher reads it to
list and install AMML and mods.

This repository is self-generated by it's own workflow. Do not hand edit any files in this repo.

## Use it

The launcher's default registry URL is the GitHub Pages address of `registry.json`:

    https://alaydriem.github.io/amml-registry/registry.json


## How a release gets in

1. A mod repo or `alaydriem/amml` creates its GitHub release. Its release workflow then sends an `amml-released`
   dispatch to this repo.
2. `publish.yml` downloads the release zip and `SHA256SUMS.txt`, and refuses the release unless:
   - the SHA-256 of the zip matches `SHA256SUMS.txt`;
   - the zip holds one folder `@<namespace>/<name>/`, and its `amml.hcl` names the same namespace, name and version;
   - the `listing` block of `amml.hcl` passes every rule (title, summary, authors, licence, links, tags, icon);
   - the repo is the one named for that mod in `mods.hcl`.
3. The workflow opens a pull request with the changed mod document and the derived files, merges it, and deploys the
   tree to GitHub Pages. A failed check leaves nothing merged and nothing deployed.
4. Running the same release again changes nothing. The same version with a different checksum is refused.

## The allow list

`mods.hcl` says which repos may publish, and which mods are `core` (installed into every instance, never removable) or
`default` (installed into new instances). To add a mod, send a pull request that adds a `mod` block. Private repos do not
publish, by convention.

## Retry or backfill

Run the `Publish` workflow by hand and fill in the release (kind, repo, namespace, name, version; for AMML also the API
version and the tested game versions).
